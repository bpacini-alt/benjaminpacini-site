# Google Site archive (captured 2026-10-20)

A full snapshot of https://sites.google.com/view/benjamin-pacini/home, taken before the move to benjaminpacini.com.

- `pages/` holds every page's HTML exactly as Google served it, in the same folder structure as the original site.
- `files/` holds every Google Drive file embedded or linked on the site (PDFs, Word docs, one audio file, and the one Google Doc and Slides deck, exported as both editable files and PDFs). File names start with the original Drive ID.
- `manifest.json` lists each page's original URL and title, each file's original name, and which pages use it. It also lists the four Google Forms, which are live forms and can't be archived.

YouTube videos are not copied; the manifest records each page's video IDs.

This folder is a record. Don't edit it. The new site is built separately.
