Learn about the 2013 Framework for Teaching (FFT), used in Idaho to evaluate teachers. Explore its domains and components, then use classroom scenarios to consider the evidence behind practice ratings.

For discussion and practice. Each vignette is original, and each rating key applies only to the evidence shown in that vignette. It is not an evaluation of a real teacher.Idaho's rule names the Framework for Teaching, Second Edition. The 2013 version used here keeps that edition's four domains and 22 components, with updated rubric wording.
